# Capturas para el README principal

El `README.md` de la raíz referencia estos archivos por nombre exacto. Grabalos/tomalos
y ponelos acá con estos nombres para que aparezcan automáticamente (no hay que tocar
el README de nuevo, ya están enlazados):

| Archivo | Qué mostrar |
|---|---|
| `demo.gif` | Flujo corto (15-25s): login → Dashboard → abrir un sector → registrar una evaluación → ver el histórico actualizarse. Es lo primero que va a ver alguien que abre el repo. |
| `dashboard.png` | La vista de Dashboard completa: tarjeta hero, ranking, radar comparativo. |
| `sector-detalle.png` | El detalle de un sector: radar + línea de evolución + comentarios. |
| `auditoria.png` | La página de Auditoría mostrando un cambio de peso con el botón "Revertir". |

Recomendado: 1280px de ancho para los `.png`, GIF a ~800px de ancho y por debajo de
10MB (GitHub no reproduce GIFs más pesados inline de forma confiable).

Este archivo (y `.gitkeep`) se pueden borrar una vez que las capturas reales estén acá.
